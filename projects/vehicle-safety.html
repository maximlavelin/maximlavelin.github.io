Vehicle Safety Intelligence: Classifying NHTSA Complaints at Scale

Deep Learning (35374)May 2026Final project
Trained and compared MLP, CNN and BiLSTM architectures on ~300,000 NHTSA vehicle safety complaints, reporting ROC and precision-recall curves, calibration, and bootstrap confidence intervals for every metric — not a single point estimate.

Problem

NHTSA receives hundreds of thousands of free-text vehicle safety complaints. Triaging them by hand does not scale. This project builds a text classification pipeline to categorise complaints automatically, comparing progressively more expressive architectures under an evaluation protocol designed to be statistically honest rather than flattering.

Data

  • ~300,000 free-text NHTSA complaint records.
  • Text cleaning, tokenisation, and TF-IDF vectorisation as the classical baseline representation.
  • [Add: target variable definition — severity class, defect category, or injury flag.]

Approach

Three architectures of increasing capacity, to test whether deep sequence models actually earn their cost over a simpler baseline on this task:

  • MLP on TF-IDF features — fast and interpretable, the bar the others have to clear.
  • CNN — captures local n-gram-like patterns in complaint text.
  • BiLSTM — models sequential context across the full complaint narrative.

Evaluation

Evaluation deliberately went beyond headline accuracy:

  • ROC and precision-recall curves — PR matters here because complaint classes are imbalanced, and ROC-AUC alone can look strong on an imbalanced problem.
  • Calibration analysis — checking whether predicted probabilities are trustworthy, not merely whether the top class is right. A model used for triage needs to be believable when it says 90%.
  • Bootstrap confidence intervals — quantifying how much each metric would move on a different sample, rather than trusting one split.
